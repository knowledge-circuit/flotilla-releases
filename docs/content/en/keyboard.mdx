`⌥` means "about threads" in Flotilla. Keys with `⌥` are read by their position on the keyboard, so on a Mac `⌥P` opens the menu and does not type π.

## Everywhere

| Key | Does |
|---|---|
| `/` | Puts the focus in the message input. |
| `⌥↑` `⌥↓` | Switches to the thread above or below. |
| `⌥P` | Opens the provider, model and effort menu. |
| `⌥T` | Shows or hides the plan panel. |
| `⌥.` | Stops the running turn of the thread on screen. |
| `Esc` | Closes the settings page, a menu or a dialog. |

## In the message input

| Key | Does |
|---|---|
| `↵` | Sends. While a turn runs, the message queues. |
| `⇧↵` | Breaks the line. |
| `⌘↵` | Sends now. With an empty input, sends the first queued message now. |
| `/` then a word | Opens the session's commands and skills. `↑` `↓` move, `Tab` fills. |
| `Esc` | Closes the command menu, or leaves the input. |

On a touch phone `↵` breaks the line and only the send button sends.

## In the inbox

| Key | Does |
|---|---|
| `1` to `4` | Answers the focused card with that option. |
| `↵` in the text field | Answers in your own words. |

## In menus and dialogs

| Key | Does |
|---|---|
| `↑` `↓` | Moves. |
| `↵` or `Space` | Opens or picks. |
| Typing | Filters, or jumps to a name. |
| `Esc` | Closes and gives the focus back. |

## Mouse only

- Drag the edge of the sidebar or the plan panel to resize it. A double click resets the width.
- Right click a thread row for its menu. On a touch device, long press.
- Paste or drop an image on the input to attach it.
